SCENE 2: First confirm it is genuinely missing
Screen action: First confirm it is genuinely missing. Open My Day and select the correct work date. Check whether copied time already exists. If a line exists but is wrong, edit it; do not add another overlapping line. Confirm the numeric Accelo Job Number with the inspector. Warning: Manual job time is a recovery route, not the normal daily workflow.

SCENE 4: Enter the missing period
Screen action: Enter the missing period. Enter the numeric Accelo Job Number — digits only. Enter the actual Started and Ended date/time. End must be later than start. Add useful details, for example: Assisted Inspector Smith — omitted from job crew. Select Underground only when the approved rule genuinely applies. Select Add time and confirm the new line appears.
